Protocol Design Guide for Creators & Reviewers

Question Quality

  • Phrase as a realistic operational question an incident commander would ask.
  • Be specific — include crisis type, phase, and context (e.g. "What is the initial attack protocol for a wildland fire in the first hour?").
  • Avoid overly generic questions ("What do you do in a fire?").

Expert Answer Quality

  • Answers are injected into LLM prompts — write as a domain expert would speak.
  • Include numbered procedures, priorities, and safety considerations.
  • Reference real standards where applicable (ICS, LCES, NIMS, WHO, etc.).
  • Aim for 3–8 sentences. Too short = weak training signal; too long = diluted context.

Procedure Steps

  • One step per line — the scenario builder extracts these as discrete available actions.
  • Start each step with an action verb: Deploy, Establish, Notify, Assess, Coordinate.
  • These steps can be directly imported into a Crisis Scenario's action list via "AI Suggest from Protocols".

Applicable Crisis Types

  • Controls which scenarios the "AI Suggest from Protocols" feature will surface this protocol for.
  • Be generous — a flood protocol may also apply to earthquake (rescue, evacuation overlap).
  • Use the same type keys as scenario types: flood, wildfire, earthquake, hazmat, tsunami, etc.
