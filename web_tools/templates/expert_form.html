Agent Design Guide for Reviewers & Creators

Command Level

  • GOLD — Strategic command: Civil Protection Director, Police/Fire/Medical/Coast Guard regional commanders. Highest weight in ER aggregation. Use for decision-makers with authority over resource allocation.
  • SILVER — Tactical/Advisory: specialists (meteorologist, physician, logistics). Provide domain knowledge but defer strategy to GOLD.

Risk Tolerance 0.0–1.0

  • Low (0.1–0.3): cautious, prioritises safety over speed. Typical for medical directors, environmental scientists.
  • Medium (0.4–0.6): balanced. Most tactical commanders.
  • High (0.7–0.9): willing to accept risk for speed/effectiveness. Fire/Police tactical roles.

Weight Preferences sum ≈ 1.0

  • These drive the MCDA scoring for each alternative. Each value is this agent's relative priority for that criterion.
  • Must sum to 1.0 — the form shows a live total and warns if off.
  • Example: a Medical Director weighs safety 0.45, effectiveness 0.30, speed 0.15, cost 0.05, public acceptance 0.05.

Confidence Level 0.0–1.0

  • The agent's self-assessed domain confidence. Used as a feature in GAT attention scoring alongside reliability history.
  • Higher = stronger voice in GAT aggregation. Keep realistic — overconfidence inflates weight unfairly.
  • Typical range: 0.75–0.95 for senior experts.

Expertise Tags

  • Machine-readable keywords used by the automatic expert selector (expert_selector.py) to match agents to scenario types.
  • Use snake_case, comma-separated. E.g. wildfire_meteorology, flash_flood_forecasting.
  • More relevant tags → more likely to be selected for appropriate scenarios.

Decision Style & Expertise Field

  • Expertise (expertise field): single snake_case domain key, e.g. severe_weather_forecasting. Used programmatically.
  • Decision Style: narrative description injected into the LLM system prompt to shape the agent's reasoning persona.
  • Notable Experience: one entry per line — each becomes a bullet in the LLM prompt context.
